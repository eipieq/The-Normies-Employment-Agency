## version 1 (recommended, ~1,200 chars)

The biggest problem with AI vibecoding isn't the code. It's homogeneity.

Every project starts with the same helpful assistant. Same tone. Same hedging. Same "Great question!" energy. You ship something that works, but nothing feels like *yours*.

NFT creators have spent years trying to give holders ongoing value. Most of it is cosmetic. I think the next wave is different: **a coworker you can actually build with.**

We just shipped something for the Normies hackathon that tests that idea.

**The Normies Employment Agency** reads on-chain data (traits, pixels, canvas history) and generates a full employment persona for each Normie: job title, work style, strengths, blind spots, and a complete system prompt.

Public: a shareable employment card anyone can view.  
Private (wallet-gated): the system prompt you import into Cursor, Claude, OpenClaw, or whatever agent stack you're vibecoding on.

The Normie isn't wallpaper on your agent. It's the personality layer.

Try it: https://normies.sandpark.co  
Browse any holder's roster: `/roster/[wallet]`

I'm formalizing this for my thesis at Madras School of Economics: **derived agent personalities** — grounded identity artifacts, ownership-linked access, and whether they actually reduce output homogeneity in real builder workflows.

If you're a holder, a creator, or building agent infrastructure, I'd love your feedback.

## version 3 (thesis-forward, academic + builder)

I'm working on a thesis at Madras School of Economics on a question that won't leave me alone:

**Can agent personality be generated, grounded, and ownership-linked — instead of hand-written and generic?**

The failure mode is *agent output homogeneity*: capable LLM output with no stable identity. Vibecoding makes it worse because the default stack starts from zero personality every time.

My prototype is live: **The Normies Employment Agency** (https://normies.sandpark.co). It derives a coworker persona from on-chain Normie data, gates the full system prompt to the current owner, and lets you export that identity into your own agent workflow.

Public employment card. Private prompt + chat for holders.

If you're building agents, studying HCI, or run an NFT project looking for real holder utility — I'd value your take.

Paper title: *Derived Agent Personalities: Grounding, Ownership, and Homogeneity in LLM-Based Builders*
